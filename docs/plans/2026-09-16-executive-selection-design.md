# A shorter Executive view

The user wants the earlier concise presentation with a few additional strong
examples and captions that assume no prior knowledge. This supersedes the rule
that both views display the complete collection. Technical retains all results.

## Eight examples in three groups

- Brains and behavior: measured recordings, predicted movie responses, human choices.
- Inspect and intervene: targeted intervention, combining modalities, saved activity.
- Robotics: DROID integration, intervention recovery.

Each card has a capability headline, a 45–75-word caption immediately below it,
one primary figure with its legend, and a link to the full experiment. Captions
explain what was done, how to read the figure, and what the result means. Essential
limits stay visible, including the use of an untrained robotics test policy.

## Preservation

Move the existing figure and its controls between Executive and Technical using
DOM placeholders. Do not duplicate figures or alter data. Technical restores each
figure to its original position and displays all 26 cards. Old section links to
unfeatured examples switch to Technical automatically. The archive remains intact.
